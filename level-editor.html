    A map workbench. One file. No installation.

    Open this HTML in a desktop browser. The city and regression slice are embedded as starting examples; they are copies, not live disk files. Open JSON binds an existing file. In Chrome/Edge, Save writes it back after you grant access; other browsers download a replacement. Open repo folder lets you choose the repository and then opens a source map.

    Select collections on the left. Click or drag objects on the map, edit fields on the right, or edit object/document JSON. Roads, zones, access spurs, reservations, districts, spawns, parking and landmarks are visualised. Visual chunks and collision JSON are also supported. Recipe-generated buildings are deliberately not guessed: their settings are editable under buildings, and the baker remains the source of truth.

    Ctrl/Cmd+S save · Ctrl/Cmd+Z undo · Ctrl/Cmd+Shift+Z redo · Delete delete selection · Esc deselect · Space + drag pan. Object movement respects the snap setting. Inspector yaw values use radians.

    JSON saves are validated for syntax, finite numbers, common dimensions, duplicate IDs and dangling source references. Invalid saves are blocked. Keep related reservations/accesses aligned when moving gameplay objects; the editor changes only the object you select.

    After saving a source file, run npm run content:bake, then your normal build/restart. This tool cannot run shell commands or rebuild package hashes. It makes no network requests and needs no CDN.
