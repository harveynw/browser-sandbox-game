# Verification evidence

These files record local functional verification, automated checks, asset budgets and performance measurements. [Testing](../testing.md) explains coverage; [performance](../performance.md) explains methodology, confounds and unqualified targets.

Screenshots and captured JSON retain their recorded environment, timestamps, source revisions and measurement values. Historical names embedded in raw captures are provenance, not product stages or current requirements. Capacity datasets are diagnostic observations, including failed latency/memory targets. They are not performance certification. Build/check outputs can be refreshed with the commands in the testing guide; do not edit measurements to match intended outcomes.
